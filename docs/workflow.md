# Workflow

This document describes the current analysis workflow used in the Digital Rodent project. The workflow aims to create reproducible normative models from resting-state rodent MRI datasets while maintaining a standardized preprocessing and quality control pipeline.

## Overview

```
Dataset selection
        ↓
Initial dataset assessment
        ↓
Split into healthy/control and diseased/altered subjects
        ↓
Quality control of raw images
        ↓
RABIES preprocessing
        ↓
Preprocessing quality assessment
        ↓
Dual regression feature extraction
        ↓
Normative modelling (PCNtoolkit)
        ↓
Application to diseased subjects
```

## 1. Dataset selection

Potential datasets are first evaluated before inclusion in the project.

Several criteria are considered:

* Availability of both anatomical and functional MRI scans.
* Public availability or permission to use the data.
* Overall data quality and completeness.
* Clear experimental design and metadata.
* Credibility of the study and acquisition protocol.
* Suitability for normative modelling.

Only datasets that satisfy these criteria are included in the analysis pipeline.

## 2. Subject grouping

After downloading and organizing a dataset, subjects are divided into:

* Healthy or control subjects
* Diseased or experimentally altered subjects

Healthy subjects are used for construction of the normative model, while diseased subjects are evaluated against the model at a later stage.

## 3. Raw data quality control

Before preprocessing, each dataset undergoes an initial quality control assessment to ensure that it can be processed successfully by RABIES.

Particular attention is given to:

* Correct orientation of anatomical and functional images.
* Consistency between the image orientation displayed by visualization software and the actual anatomical structures.
* Image completeness.
* Obvious acquisition artefacts.
* Missing scans or corrupted files.

Datasets or subjects failing these checks are corrected where possible or excluded from further analysis.

## 4. RABIES preprocessing

Datasets that pass the initial quality control are preprocessed using the RABIES pipeline.

The preprocessing includes standard steps for resting-state fMRI preprocessing such as image registration, motion correction, artifact correction, nuisance regression, and spatial normalization.

Multiple preprocessing parameter configurations may be evaluated to optimize the quality of individual datasets.

Currently, these preprocessing parameters are selected manually. One of the long-term objectives of this project is to semi-automate the selection of optimal preprocessing parameters based on quality metrics.

## 5. Preprocessing quality assessment

Following preprocessing, each subject is evaluated using the quality control reports generated by RABIES.

These reports include several quality metrics, including:

* Estimated subject motion.
* Motion over time.
* Brain alignment with the group template.
* Registration quality.
* Effectiveness of artifact correction.
* Overall preprocessing quality.

Each subject is reviewed individually.

Subjects are either:

* accepted for further analysis,
* reprocessed using different preprocessing parameters,
* or excluded if sufficient preprocessing quality cannot be achieved.

## 6. Dual regression feature extraction

After all accepted subjects have successfully completed preprocessing, dual regression values are extracted.

The resulting dual regression values form the imaging features that are used as input for normative modelling.

## 7. Normative modelling

The extracted dual regression features are analysed using the PCNtoolkit.

Healthy subjects are used to construct a normative model. The toolkit automatically separates the available data into training and testing sets for model evaluation.

The normative model incorporates imaging features together with selected covariates and batch effects.

Several modelling approaches are available within PCNtoolkit. The final modelling strategy will be selected following further evaluation.

The outputs generated by PCNtoolkit include:

* A trained normative model.
* Model evaluation metrics.
* Quantile–Quantile (QQ) plots.
* Centile plots.
* Z-score estimates for individual subjects.
* Predicted values and residuals.

After a normative model has been established using healthy control subjects, diseased or experimentally altered subjects are evaluated against the normative model.

## Future developments

Several components of the workflow are currently under active development.

These include:

* Semi-automated preprocessing parameter selection.
* Automated quality control assessment.
* Standardized extraction of imaging features.
* Expanded normative modelling strategies.
* Automated reporting and visualization of results.
