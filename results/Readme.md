# Results

This directory contains processed outputs generated from the Digital Rodent project.

## Folder structure

### dual_regression/

Dual regression summary tables generated after preprocessing with RABIES. Each file is named according to the dataset ID defined in `data/datasets.tsv`.

Example:
01_DR_results_all_subjects.csv = Environmental enrichment dataset	ds005636	10.18112/openneuro.ds005636.v1.0.

### model/

Outputs from normative modelling analyses, Consisting off PLACEHOLDER.

### plots/

Figures generated from analyses for reports, publications, and quality control.

Additional result types may be added as the project develops.

## Reproducibility

Whenever possible, every result in this directory should be reproducible using the scripts provided in the `scripts/` directory.
